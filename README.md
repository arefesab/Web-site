This is a full-stack web application that simulates a travel agency portal. On this site you can find hotels and flights; admins can create, edit and delete hotels and flights.
Developed the back-end logic and server-side operations using ASP.NET, with a SQL Server database to manage hotels and flights data.
Designed the front-end interface with HTML, CSS, and JavaScript.
For implementing this web application many diagrams such as Class Diagram, CRC, ERD, Sequence, State and Swimlane were drawn.
You should open the code file with Visual Studio Code and for diagrams use Draw.io app.
The attached PDF file contains the diagrams.
